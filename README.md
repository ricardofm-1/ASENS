# ASENS — Asentum Name Service

Register `.ase` names that point at an Asentum address. Search a name, connect an Asentum wallet (browser extension or Telegram), and register or renew it on the Asentum testnet. Connected wallets can see their names, set a primary name, edit profile records, and transfer names.

## Contracts (Asentum testnet)

- Registry: `0x81f34ec12752ea464ec5bc6d879ac134ec481857`
- Controller: `0xc11320f6b10bb91a5ab00da54da6c35be39bbfab`

## Develop

npm install
